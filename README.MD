# PennyWise

PennyWise is a personal finance app for tracking expenses and keeping monthly spending on plan. Sign in to manage your own expense history, create spending categories, set monthly and per-category budgets, and review spending with charts. You can also schedule recurring expenses and choose a preferred currency (USD, CAD, GBP, or EUR).

## Project layout

```text
frontend/   React 19 interface built with Vite
backend/    Java 21 / Spring Boot REST API
```

The frontend contains the main app and focused components for authentication, expenses, budgets, charts, and recurring expenses. The backend groups API code by feature (`auth`, `transaction`, `budget`, `category`, and `recurring`). It uses Spring Data JPA with PostgreSQL; recurring expenses are generated by a scheduled backend task.

## Run locally

Prerequisites: Java 21, Node.js with npm, and PostgreSQL.

1. Create a PostgreSQL database named `pennywise` and a database user with access to it.
2. Create `backend/.env` with your database credentials:

   ```properties
   DB_USERNAME=your_database_user
   DB_PASSWORD=your_database_password
   ```

   The backend also loads a `.env` at the repository root if you prefer to keep local settings there. `.env` files are ignored by Git.
3. Start the API from the repository root:

   ```sh
   cd backend
   ./mvnw spring-boot:run
   ```

4. In another terminal, start the frontend:

   ```sh
   cd frontend
   npm install
   npm run dev
   ```

Open the local URL printed by Vite. Its development server proxies `/api` requests to the backend at `http://localhost:8080`.

## Useful commands

From `frontend/`:

```sh
npm run dev       # Start the Vite development server
npm run build     # Build the production frontend
npm run lint      # Run Oxlint
```

From `backend/`:

```sh
./mvnw spring-boot:run   # Start the API
./mvnw test              # Run backend tests
```

## Notes

- API routes are under `/api`; authentication uses a server-side session cookie.
- The backend expects PostgreSQL on `localhost:5432` with database `pennywise` by default. You can override its connection settings with Spring datasource environment properties.
- Database schema changes in `backend/src/main/resources/db/manual/` are manual SQL scripts; apply them when upgrading an existing database as directed by the project.
